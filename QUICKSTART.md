## ⚡ Instalación Rápida (30 segundos)

```bash
# 1. Clonar
git clone https://github.com/0xjuarez/pentia.git
cd pentia

# 2. Instalar (instalación base)
chmod +x install.sh
./install.sh

# 3. Usar
pentia --help
```

**¿Problemas?** → Ve a [TROUBLESHOOTING.md](TROUBLESHOOTING.md)

## 🎯 Comandos Principales

```bash
pentia                      # Menú principal
pentia --help               # Todos los comandos
pentia version              # Ver versión
pentia serve                # Interfaz web (http://127.0.0.1:8000)
pentia chat                 # Chat con IA
pentia recon example.com    # Recon completo
pentia web example.com      # Enumeration web
pentia cve target apache 2.4.49  # CVE intelligence
```
